### 配置と振り分け

所有ホストを `((userID - 1) % 5) + 1` で固定します。例えば余り1のIDは`isucon-1`が所有します。5台でGoアプリと各ローカルMySQLを動かし、ユーザー状態、通常セッション、BAN、プレゼントは**所有ホストだけ**が読み書きします。初期データはまず各DBに同じ内容を置き、初期化用SQLの分割は行いません。

| リクエスト | 振り分け |
| --- | --- |
| `POST /user` | nginxが5台へ配分。受けたホストでIDを発行して作成する |
| `POST /login` | Goが本文の`userId`を読み、所有ホストへ転送する |
| `/user/:userID/...` | GoがURLのIDで所有ホストへ転送する |
| `/admin/user/:userID`とBAN | 管理者認証を保ったまま所有ホストで実行する |
| その他の`/admin`、`/initialize` | 1号機を入口とする |

転送判定はAPI・認証middlewareより前に置きます。現行middlewareはBANとセッションをローカルDBで確認するため、先に実行すると非所有ホストの古いデータを参照します。転送時は元のメソッド、本文、`x-isu-date`、`x-master-version`、`x-session`、応答コード・本文・計測用ヘッダーを保持します。所有ホストでは既存の認証から状態処理までを実行し、転送は一回に制限します。書込みの自動再試行は、二重実行を避けるため設けません。[現行ルートとmiddleware](</Users/mineo/worktrees/EkeMinusYou/isucon12-final-3/tue/webapp/go/main.go:92>)

### ID、共通データ、初期化

- **ID発行**：現在のファイル採番は5台とも同じ開始値なので、そのままでは重複します。各ホストが自分の所有余りに属するIDだけを5刻みで発行します。ユーザー以外の動的IDも同じ方式とし、予約済み上限を永続ファイルへ先に記録します。既存の採番ファイルがあれば、その上限以上で自ホストの余りに合う値へ進めます。新規ユーザーのIDは作成したホストへ必ず戻る規則です。[現行採番](</Users/mineo/worktrees/EkeMinusYou/isucon12-final-3/tue/webapp/go/id_generator.go:13>)
- **マスタ・管理者データ**：1号機のMySQLを正本とし、各アプリはローカルのユーザーDBとは別の接続で参照します。`PUT /admin/master`は同一トランザクションでマスタの改訂番号も更新します。各ユーザーリクエストは改訂番号を確認し、変わった場合だけマスタを読み直します。同一リクエスト内では一つのマスタスナップショットを使います。管理者セッションも1号機を参照します。これには1号機MySQLへの私設網からの接続設定が必要です。[現行マスタキャッシュ](</Users/mineo/worktrees/EkeMinusYou/isucon12-final-3/tue/webapp/go/master_state.go:28>)、[管理者更新](</Users/mineo/worktrees/EkeMinusYou/isucon12-final-3/tue/webapp/go/admin.go:474>)
- **初期化**：公開`POST /initialize`を受ける1号機が、5台のローカル初期化を**並行して**起動し、全台成功後に`{"language":"go"}`を返します。各ホストは自分の状態キャッシュ・永続ログとDBを初期状態へ戻します。`task db-recreate`側も5台のDB再作成後、公開初期化を1号機で一度だけ呼ぶよう競技固有のdeploymentを変更します。現状は各アプリで`/initialize`を呼ぶ設定なので、二重初期化を避ける変更が必要です。公式制限は60秒です。[現行初期化](</Users/mineo/worktrees/EkeMinusYou/isucon12-final-3/tue/webapp/go/main.go:288>)、[deployment](</Users/mineo/worktrees/EkeMinusYou/isucon12-final-3/tue/tools/contest/deployments.yaml:24>)、[公式要件](</Users/mineo/worktrees/EkeMinusYou/isucon12-final-3/tue/docs/official/manual.md:190>)
